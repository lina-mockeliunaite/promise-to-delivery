## What we learned today

- This morning's offline refusal was not a date problem. The cache key holds each document's date, and a document added as "A new document" gets today's date, so its key changes. Filing as "A new version of …" inherits the original date and hits the cache.
- Both demos now run with no API key when filed as the scripts describe.

## How to start the demo from scratch

1. Terminal (Cmd + Space, "Terminal"). Window 1:
   ```
   lsof -ti :8000 | xargs kill
   lsof -ti :5173 | xargs kill
   cd ~/Desktop/"From Promise to Delivery"/promise-to-delivery
   source .venv/bin/activate
   read -s ANTHROPIC_API_KEY && export ANTHROPIC_API_KEY
   [ -n "$ANTHROPIC_API_KEY" ] && echo "key set" || echo "key missing"
   .venv/bin/python reset_demo.py
   .venv/bin/python -m uvicorn api:app --host 127.0.0.1 --port 8000
   ```
   (Skip the two key lines and run `unset ANTHROPIC_API_KEY` instead to test offline.)
2. Window 2 (Cmd + N):
   ```
   cd ~/Desktop/"From Promise to Delivery"/promise-to-delivery/frontend
   npm run dev
   ```
3. Private browser window at http://127.0.0.1:5173. Set your name in the app.
4. Restart the server without losing progress: Ctrl + C in Window 1, then the `read -s` line and the `uvicorn` line, no reset.
