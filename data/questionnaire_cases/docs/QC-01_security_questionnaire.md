# Vendor security questionnaire — Kestrel Remit

Date: 5 November 2026

Completed by Elva (Security and Solutions) for Kestrel Remit's vendor risk team.

| # | Question | Elva response |
|---|---|---|
| 1 | Does the platform support single sign-on (SSO)? | Yes. Elva supports SAML 2.0 single sign-on for all Kestrel Remit users from go-live. |
| 2 | Is multi-factor authentication enforced? | Elva will enforce multi-factor authentication for every Kestrel Remit administrator account. |
| 3 | How is customer data encrypted at rest? | All Kestrel Remit data will be encrypted at rest with AES-256. |
| 4 | Where will Kestrel Remit data be stored? | Kestrel Remit data will be stored and processed only in Singapore. |
| 5 | Do you hold a SOC 2 Type II report? | Elva is working towards SOC 2 Type II and expects the report in the second half of 2027. |
| 6 | How often is the platform penetration-tested? | An independent penetration test is performed every year, and Elva will share the executive summary with Kestrel Remit on request. |
| 7 | Can wallet screening run before each payout is released? | Elva will screen every NUSD payout on Arbitrum in real time before release. |
| 8 | Who manages user access on the customer side? | Kestrel Remit is responsible for approving and removing its own user accounts. |
| 9 | Please describe your incident response process. | See the Elva Security Pack, section 4. |
| 10 | Will you notify us of a security incident affecting our data? | Yes. |
| 11 | Is a full audit history kept for alerts? | Elva provides full case audit history for every alert raised on Kestrel Remit payouts. |
