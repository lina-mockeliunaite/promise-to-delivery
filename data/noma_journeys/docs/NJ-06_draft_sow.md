# DRAFT Statement of Work — Noma Journeys

Date: 12 October 2026

Between Aivuna ("Provider") and Noma Journeys ("Customer"). Draft for discussion. Annex A forms part of this Statement of Work.

## 1. Purpose

This Statement of Work describes implementation of the Provider's AI customer-support assistant, which answers guests' questions about bookings, booking changes and refunds.

## 2. Channels

Provider will operate the Assistant on chat and email for the Customer's guests, as described in Annex A.

## 3. Booking system

The Assistant will read booking records from the Customer's booking system through the Provider's booking system connector.

## 4. Human handoff

The Assistant will hand over conversations it cannot resolve to the Customer's human agents, with the full conversation attached.

## 5. Languages

The languages in which the Assistant responds are specified in the Agreement.

## 6. Governance

The parties will hold a weekly project status meeting during implementation.

## Annex A — Service Description

A.1 The Assistant responds to guest enquiries about bookings, changes and refunds by chat and by email.

A.2 The Assistant reads a guest's booking record before it answers a question about that booking.

A.3 This service description applies to guest enquiries received through the Customer's chat and email channels.
